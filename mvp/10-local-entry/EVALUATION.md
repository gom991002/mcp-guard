## 한눈에 보기

| 평가 | 확인된 결과 | 판단 |
| --- | --- | --- |
| 1단계 규칙 | 시험 데이터 악성 183개 중 **119개 검토 보류**, **64개 놓침**. 정상 230개 중 **47개 검토 보류** | 규칙이 현재 판정을 담당. 검토 신호가 없는 악성은 이 방식으로 잡지 못함 |
| B 점수 모델 | PR-AUC **0.7472** (95% CI 0.7042–0.7918). 신호 개수만 쓴 비교값 **0.6378** | 보류된 패키지의 우선순위와 이유 기록에 사용. 같은 재현율에서 오탐은 규칙보다 **1개** 적어 판정에는 사용하지 않음 |
| 알려진 악성 유사도 | 악성 **53/183** 일치, 정상 **0/230** 일치. 규칙이 놓친 악성을 추가로 잡은 수 **0** | 검토 근거로만 사용. 유사도만으로 보류·차단하지 않음 |
| LLM 검토 도우미 | 보류된 악성 **29/30**, 정상 **27/30**을 `suspicious`로 분류. `likely_benign`은 양쪽 모두 **0/30** | 정상과 악성을 구별해 검토 부담을 줄이지 못함. 기본 꺼짐 유지 권장 |

규칙의 **재현율 0.6503**은 `119 ÷ 183`, 정상 검토 비율 **0.2043**은 `47 ÷ 230`입니다. 모델 기준값을 사용했을 때도 악성 119개를 검토 보류했고, 정상 검토는 46개로 1개만 줄었습니다. 수치는 시험 데이터의 관측값이며 실제 설치 환경의 성능을 보증하지 않습니다.

## LLM 평가를 읽는 법

LLM 평가는 규칙이 이미 검토 보류한 표본에서 악성 30개와 정상 30개를 골라 수행했습니다. 악성 1개와 정상 3개는 `unclear`였고, 정상 27개도 `suspicious`였습니다. 따라서 `likely_benign` 0건을 안전성 증명으로 읽을 수 없습니다. 보고서의 `likely_benign` 비율 95% 신뢰구간 상한은 각 그룹에서 **0.1135**입니다. 평균 처리 시간은 **65.4초/건**으로 기록돼 있습니다.

- 이 결과는 1단계 B 신호의 평가입니다. 원격 게이트웨이의 3단계 M4 응답 오염 판정·4단계 봉쇄가 완료됐다는 뜻은 아닙니다.
